# Android 1.1.3

版本码：10103。应用 ID、签名方式和 WebView origin 保持不变，支持覆盖安装。

- 新安装默认服务器为 `https://music.102.yuna.team`；保留用户自选服务器。
- 启动时网络、TLS、超时或服务停机不再删除已保存的会话令牌；显示重试连接入口。
- 仅在服务端明确返回认证失效、用户主动退出或实际切换服务器时清除会话。
- 未改变服务器地址时保存设置，不再清除登录状态。
- 已完成的浏览器认证回调不再阻断下次启动恢复；授权码成功兑换后先保存会话，再恢复 WebSocket。
- 使用服务器已有的咲夜 SVG 图案生成各密度桌面图标、自适应图标和网页图标。

旧版本若已经删除令牌，需要重新登录一次；新版不能恢复已经删除的凭据。
请覆盖安装，不必卸载或清除 App 数据。尚需真机验证 OEM 图标显示与断网/重启恢复。
