# Android 1.2.0

版本码：10200。应用 ID `dev.uwen.yuzujukebox` 和原有签名方式保持一致，用于覆盖更新原来的 App。

- 同步本轮前端改版：系统字体、侧栏／手机导航、深浅主题与封面卡片；热门、播放历史和本房热门前移。
- 当前曲目控制区增加房间暂停／继续、下一首与房间音量，遵循房间控制权限；底部常驻播放栏保留。
- 红魔馆彩蛋皮肤：绯红、酒红与古金色，边角 SVG 吸血鬼纹章、钟表和飞刀。手机账户菜单内可切换，皮肤选择持久化；无独立时停按钮或效果。
- 前端移除随便听听、私人 FM 和心动模式入口；其它歌单／榜单播放能力保留。
- 修正榜单卡片封面与标题对齐；全屏按断点挂载单套视图，精简背景，延后高清图与歌词加载，减少切换开销。
- Android 保留原有前台服务、锁屏控制、歌词桥和后台播放行为；网页专属跟随开关及 Cookie 偏好只作用于浏览器。

安装方式：将 APK 传到手机，直接打开并选择更新；无需卸载或清除数据。已保存的服务器、会话和皮肤偏好由同一应用数据目录延续。若手机原包使用不同签名，系统会拒绝覆盖更新，此时不要通过卸载规避。

本地 APK 的资源、版本和签名检查与真实手机体验是分开的验证阶段；未进行真机安装、后台播放或流畅度实测。
